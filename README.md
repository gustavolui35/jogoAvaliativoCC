## Sobre o Jogo

GTA Taxi Driver é um jogo desenvolvido em Python utilizando a biblioteca Pygame.

No jogo, o jogador controla um taxista que percorre as ruas da cidade coletando passageiros e evitando colisões com outros veículos. O objetivo é alcançar a maior pontuação possível e superar os recordes registrados no sistema.

O jogo possui tela de boas-vindas, sistema de pontuação, registro de partidas, sistema de pausa, síntese de voz e elementos visuais animados.
